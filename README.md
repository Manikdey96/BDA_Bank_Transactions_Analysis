\# Big Data Analysis of Bank Transactions



Hadoop MapReduce (3 analyses) and Apache Pig (5 analyses) on a 200,000-row

bank transaction dataset, using a Docker-based Hadoop cluster.



\## Structure

\- `docker-compose.yml` — Hadoop cluster definition

\- `scripts/` — MapReduce mapper/reducer (awk) and Pig Latin script

\- `results/` — Output of all 3 MapReduce and 5 Pig analyses
